## Copilot Agent Kit
Copilot Agent kit is free, open source toolkit that provides makers and administrators tools for testing, governing, analyzing, and optimizing custom AI agents at scale

*Different modules in Copilot Agent Kit are listed below*

> `Agent Inventory` <br/>
Displays list and counts of agents in your tenant along with a rich inventory details

> `Agent Review Tool` <br/>
Static analysis that detects common anti-patterns in agent configurations before they reach production
>

> `Compliance Hub` <br/>
Risk scoring, automated quarantine workflows, and admin follow-up tracking for agent compliance management
>

> `Test Automation` <br/>
Batch testing with multi-turn conversations, LLM-graded evaluation, and Excel-based test set management — complementing Copilot Studio's built-in evaluation framework
>

> `Rubric Refinement` <br/>
AI-generated evaluation rubrics that define consistent quality scoring criteria for agent responses
